# Сайт tadeystatus.com.ua

## Як додати об'єкт
1. Фото: у папці `media` натисни **Add file → Upload files**, завантаж фото (назва латиницею, напр. `pasichna-2k.jpg`).
2. Відкрий `objects.json` → олівець (Edit) → скопіюй будь-який блок `{ ... }`, встав після нього через кому й зміни поля.
3. **Commit changes**. Через хвилину сайт оновиться сам.

## Поля об'єкта
- `id` — унікальна коротка назва латиницею
- `filter` — `Новобудови`, `Вторинка` або `Оренда`
- `badge` — `Продаж` або `Оренда`
- `photo` — `media/назва-фото.jpg` (порожньо = заставка)
- `title`, `complex`, `addr`, `price`
- `facts` — 2–3 коротких факти для картки
- `desc` — опис (необов'язково)
- `specs` — характеристики для детальної сторінки

## Як не зламати objects.json
Лапки подвійні `"`, між блоками кома, після останнього блоку коми немає.
